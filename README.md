# ΔΕΛΦΟΙ

Un póster digital brutalista inspirado en el Oráculo de Delfos, la cerámica ática y las máximas de la antigua Grecia.

**Web:** [gonzalo123.github.io/delfos](https://gonzalo123.github.io/delfos/)

## Funciones

- «Conócete a ti mismo» y «Nada en exceso» como inscripciones protagonistas.
- El resto de máximas rota automáticamente en griego y español cada 16 segundos.
- Cada cambio recompone progresivamente las letras antes de fijar la nueva máxima.
- La máxima cambia también de inclinación en cada aparición, manteniendo ambas traducciones en el mismo eje.
- Una franja de barrido vertical aporta el acabado de televisión antigua.
- La misteriosa E de Delfos aparece como una referencia secundaria.
- Rotación lenta de cerámica griega usando imágenes locales ligeras.
- Diseño responsive y soporte para `prefers-reduced-motion`.
- Sin build ni dependencias externas.

## Desarrollo

Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

## GitHub Pages

Todo usa rutas relativas y archivos estáticos. Publica la raíz de la rama `main` desde **Settings → Pages**; no hace falta ningún proceso de compilación.
